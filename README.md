# Portfolio professionnel — D-CLIC

## 📌 Présentation

Ce projet consiste en la création d’un portfolio professionnel réalisé dans le cadre de la formation D-CLIC en développement web.

Ce portfolio a pour objectif de présenter mon profil, mes compétences, mes projets et mon évolution dans le domaine du développement web.

## 🎯 Objectifs

Le portfolio permet de :

* présenter mon profil professionnel ;
* mettre en avant mes compétences techniques ;
* présenter mes différents projets ;
* montrer mon évolution dans le développement web ;
* disposer d’une présence professionnelle en ligne.

## 👥 Public cible

Le portfolio s’adresse principalement :

* aux recruteurs ;
* aux entreprises du secteur numérique ;
* aux professionnels du web ;
* aux potentiels clients ou collaborateurs.

## 💻 Compétences

Les principales compétences présentées dans le portfolio sont :

* HTML5
* CSS3
* JavaScript
* Responsive Design
* UI / Web Design
* SEO et Web Analytics

## 🚀 Projets

### Style Gallery

Projet de site e-commerce consacré à la mode féminine, avec une interface élégante et responsive.

### Portfolio D-CLIC

Portfolio professionnel réalisé dans le cadre du projet final de la formation D-CLIC.

### Mini-projets HTML/CSS

Ensemble de travaux pratiques réalisés afin de mettre en application les notions apprises en HTML et CSS.

## 🛠️ Technologies utilisées

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## 📱 Responsive Design

Le portfolio est conçu pour s’adapter aux différents formats d’écran :

* ordinateur ;
* tablette ;
* smartphone.

Une attention particulière est portée à la lisibilité, à la navigation et à l’accessibilité.

## 🎨 Conception

La conception du portfolio a été réalisée en plusieurs étapes :

1. définition de l’objectif et du public cible ;
2. préparation du contenu ;
3. création d’une première version du wireframe avec Stitch ;
4. amélioration du wireframe dans une seconde version ;
5. intégration du portfolio en HTML, CSS et JavaScript ;
6. adaptation aux différents écrans.
